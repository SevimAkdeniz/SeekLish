# SeekLish

SeekLish, İngilizce kelime öğrenimini oyunlaştırarak kalıcı hale getiren, kullanıcı dostu bir eğitim platformudur. Geliştirilmiş test sistemiyle kelimeler 6 farklı zaman diliminde tekrar edilir.

## Özellikler

- Günlük kelime testi
- 6 aşamalı öğrenme algoritması
- Örnek cümle, resim ve ses desteği
- Kullanıcıya özel ilerleme raporları
- Rol bazlı giriş sistemi (admin, kullanıcı)
- AI destekli hikaye/görsel üretimi

## Kurulum

Aşağıdaki adımları takip ederek projeyi çalıştırabilirsiniz:

1. Reponun kopyasını alın:
git clone https://github.com/SevimAkdeniz/SeekLish.git

2. Dizin içerisine girin:
cd SeekLish

3. Gerekli modülleri yükleyin:
npm install

4. Uygulamayı başlatın:
npm start


Uygulama çalıştığında şu adrese gidin:  
http://localhost:3000

## Kullanılan Teknolojiler

- Node.js, Express
- HTML, CSS, EJS
- MySQL, Sequelize ORM
- express-session, bcrypt
- Stable Diffusion API (AI görselleri)
